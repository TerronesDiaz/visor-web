# visor-web 3.2.0

El servicio de impresión imprime el comprobante de abono y el estado de cuenta de Cuentas por Cobrar, y corrige el pagaré de las ventas a crédito, cuyas letras salían ilegibles.

El comprobante de abono muestra el cliente, quién cobró, la forma de pago, cuánto se aplicó a cada venta o remisión con su saldo anterior y restante, el total abonado en número y en letra, el saldo pendiente total del cliente y una línea para firma. El estado de cuenta muestra cuánto debe el cliente, cuánto ha pagado, lo vencido y por vencer, cada documento pendiente con su total, pagado y saldo, y los últimos abonos.

El pagaré de las ventas a crédito ya no imprime caracteres extraños en las palabras con acento, corta los renglones entre palabras en lugar de a la mitad, pone la fecha de emisión donde antes ponía la de vencimiento y, si el cliente no tiene días de crédito, deja un espacio para escribir la fecha de pago en lugar de "---".

El diagnóstico del servicio (/health) informa qué formatos admite, para que el POS ofrezca el PDF cuando el Visor instalado todavía no tiene los nuevos. Los botones para imprimir estos tickets requieren Terrones POS 2026.11.01.3 o posterior.

Validación: 8 pruebas de los formatos (ASCII, renglones de 48 caracteres, montos, pagaré con y sin vencimiento) y prueba de punta a punta con el POS local contra el servicio con la impresora sustituida por archivos.
