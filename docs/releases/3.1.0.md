# visor-web 3.1.0

Al presionar Instalar actualización, una ventana muestra el avance paso a paso: respaldo, instalación, base de datos, arranque y comprobación. Al terminar confirma el resultado. Si algo falla, explica el motivo, permite copiar el detalle y Terrones POS sigue con la versión anterior.

Antes de cerrar el POS, el visor revisa que el actualizador esté registrado, que no haya otra actualización en curso, que haya espacio suficiente en disco y que la base de datos local esté iniciada. Si falta algo, lo indica sin cerrar nada.

La ventana de estado (F9) muestra la fase de la instalación en curso, el resultado del último intento con un botón para ver su registro y el estado de la actualización en la nube. Una instalación que deja de reportar avance durante 15 minutos se marca como interrumpida y puede reintentarse.

Las fases detalladas requieren Terrones POS 2026.10.30.2 o posterior; con versiones anteriores la ventana muestra el estado general.

Validación: 37 pruebas del visor, incluidas historial de intentos, instalación abandonada, revisión previa y consistencia de fases con la ventana de progreso; la ventana se probó en Windows PowerShell 5.1 con una instalación exitosa y una fallida.
